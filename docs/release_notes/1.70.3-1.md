# Percona Search for MongoDB {{ page.meta.version }} ({{date.1_70_3}})

[Installation](../install-mongot.md){.md-button}

This release of Percona Search for MongoDB is based on `mongot` 1.70.3, bringing the latest upstream improvements and fixes. For a complete list of changes, see the [MongoDB release notes :octicons-link-external-16:](https://www.mongodb.com/docs/search/self-managed/current/release-notes/#mongot-v1701){:target="_blank"}.

!!! warning "Technical Preview"
    Percona Search for MongoDB 1.70.3-1 is available as a technical preview.

    We recommend that early adopters use this release for testing purposes only and not in production environments.

We are pleased to introduce **Percona Search for MongoDB 1.70.3-1**. Percona Search for MongoDB integrates the Apache Lucene-based `mongot` search engine with Percona Server for MongoDB. It keeps search indexes synchronized with database changes and processes search requests received through `mongod` or `mongos`.

## Release highlights

Percona Search for MongoDB 1.70.3-1 provides the following capabilities:

- [Full-text search](../full-text-search-overview.md): Run relevance-based searches with the `$search` aggregation stage.

- [Vector search](../vector-search-overview.md): Find documents based on semantic similarity with the $vectorSearch aggregation stage. Create vector indexes, filter the search scope, and retrieve a similarity score for each result.

These capabilities support keyword search, semantic search, recommendation systems, and retrieval-augmented generation applications that work directly with data stored in Percona Server for MongoDB.
