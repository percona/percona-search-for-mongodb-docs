# Percona Search for MongoDB {{ page.meta.version }} ({{date.1_79_1_4}})

[Installation](../install-mongot.md){.md-button}

Percona Search for MongoDB 1.79.1-4 updates its bundled Temurin JDK and Java libraries to address reported vulnerabilities.

## Changelog

### New Features

- [PS4M-19](https://perconadev.atlassian.net/browse/PS4M-19): Added CycloneDX 1.6 SBOMs to release archives and packages, and attached SBOMs to Docker images. See [Software Bill of Materials](../sbom.md).

### Security fixes in bundled components

#### High severity

- [CVE-2026-114938](https://www.cve.org/CVERecord?id=CVE-2026-114938): Updated Temurin from 21.0.11 to 21.0.13.1 to address 61 OpenJDK CVEs affecting JDK 21. The main issue has CVSS 8.1 and affects the Base64 intrinsic on x86-64 with AVX-512 VBMI. See the [OpenJDK advisories](https://openjdk.org/groups/vulnerability/advisories/) from July 21 through November 17, 2026.
- [CVE-2026-93451](https://www.cve.org/CVERecord?id=CVE-2026-93451) and [CVE-2026-108106](https://www.cve.org/CVERecord?id=CVE-2026-108106): Updated snappy-java from 1.1.10.8 to 1.1.10.10.
- [CVE-2026-102554](https://www.cve.org/CVERecord?id=CVE-2026-102554): Removed the Guava 32.0.1 copy pulled in through protobuf.

#### Medium severity

- [CVE-2026-116590](https://www.cve.org/CVERecord?id=CVE-2026-116590): Updated snappy-java to 1.1.10.10.
- [CVE-2026-118259](https://www.cve.org/CVERecord?id=CVE-2026-118259): Updated OpenTelemetry Java from 1.62.0 to 1.67.0.

#### Low severity

- [CVE-2026-10532](https://www.cve.org/CVERecord?id=CVE-2026-10532) and [CVE-2026-9828](https://www.cve.org/CVERecord?id=CVE-2026-9828): Updated Logback from 1.5.25 to 1.6.5.

A Grype scan of the 1.79.1-4 runtime dependencies found no known vulnerabilities.

# Percona Search for MongoDB {{ page.meta.version }} ({{date.1_79_1_4}})

[Installation](../install-mongot.md){.md-button}

Percona Search for MongoDB 1.79.1-4 updates its bundled Temurin JDK and Java libraries to address reported vulnerabilities.

## Changelog

### New features

- [PS4M-19](https://perconadev.atlassian.net/browse/PS4M-19): Added CycloneDX 1.6 SBOM files for tarballs and packages, plus OCI-attached SBOMs for Docker images. For details, see [Software Bill of Materials](../sbom.md).

### Security fixes in bundled components

This release updates the bundled Java runtime and libraries to address the following vulnerabilities.

#### High severity

- [CVE-2026-114938](https://www.cve.org/CVERecord?id=CVE-2026-114938): Updated Eclipse Temurin from 21.0.11+10 to 21.0.13.1+2. The fix addresses memory corruption in the Base64 decoder on x86-64 CPUs with AVX-512 VBMI. CVSS 8.1; exploitation could cause denial of service and, in some cases, remote code execution. This JDK update addresses 61 OpenJDK CVEs affecting JDK 21. See the [OpenJDK advisories](https://openjdk.org/groups/vulnerability/advisories/) published from July 21 through November 17, 2026.
- [CVE-2026-93451](https://www.cve.org/CVERecord?id=CVE-2026-93451), [CVE-2026-108106](https://www.cve.org/CVERecord?id=CVE-2026-108106): Updated snappy-java from 1.1.10.8 to 1.1.10.10. Crafted compressed input could corrupt memory or trigger excessive allocation, causing denial of service.
- [CVE-2026-102554](https://www.cve.org/CVERecord?id=CVE-2026-102554): Replaced the older Guava copy pulled in through protobuf with Guava 33.7.2. This fixes unbounded memory allocation during Java deserialization, which could cause denial of service.

#### Medium severity

- [CVE-2026-116590](https://www.cve.org/CVERecord?id=CVE-2026-116590): Updated snappy-java to 1.1.10.10. Invalid array ranges could crash the JVM during copy operations.
- [CVE-2026-118259](https://www.cve.org/CVERecord?id=CVE-2026-118259): Updated OpenTelemetry Java from 1.62.0 to 1.67.0. Crafted tracestate headers could cause excessive CPU use during parsing.

#### Low severity

- [CVE-2026-10532](https://www.cve.org/CVERecord?id=CVE-2026-10532), [CVE-2026-9828](https://www.cve.org/CVERecord?id=CVE-2026-9828): Updated Logback from 1.5.25 to 1.6.5 to fix restricted object injection issues in HardenedObjectInputStream.

A Grype scan of the 1.79.1-4 runtime dependencies found no known vulnerabilities.
