# Percona Search for MongoDB {{ page.meta.version }} ({{date.1_79_1_4}})

[Installation](../install-mongot.md){.md-button}

We are pleased to introduce Percona Search for MongoDB **1.79.1-4**. This release updates its bundled Temurin JDK and Java libraries to address reported security vulnerabilities and adds CycloneDX 1.6 SBOMs to release archives and packages, with SBOMs attached to Docker images.

This release is based on **mongot 1.79.1**, bringing the latest upstream improvements and fixes. For a complete list of changes, see the [MongoDB Search release notes :octicons-link-external-16:](https://www.mongodb.com/docs/search/self-managed/current/release-notes/#release-notes){:target="_blank"}.

## Release Highlights

### Software Bill of Materials (SBOM)

Starting with Percona Search for MongoDB **1.79.1-4**, each release includes a CycloneDX 1.6 SBOM in JSON format. An SBOM is a machine-readable inventory of the components and dependencies included in a software release. The tarball and package SBOMs describe the `mongot` bundle and its dependencies. The SBOM attached to a Docker image also covers the image's operating system packages.

SBOMs are distributed through the following channels:

- **Binary tarballs:** `percona-search-mongodb/percona-search-mongodb-<version>.cdx.json`
- **RPM and DEB packages:** `/usr/share/doc/percona-search-mongodb/percona-search-mongodb-<version>.cdx.json`
- **Docker images:** The SBOM is attached to the image as an OCI artifact.

### Security fixes in bundled components

#### High severity

- [CVE-2026-114938 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-114938){:target="_blank"}: Updated Temurin from 21.0.11 to 21.0.13.1 to address 61 OpenJDK CVEs affecting JDK 21. The main issue has CVSS 8.1 and affects the Base64 intrinsic on x86-64 with AVX-512 VBMI. See the [OpenJDK advisories :octicons-link-external-16:](https://openjdk.org/groups/vulnerability/advisories/){:target="_blank"} from July 21 through November 17, 2026.
- [CVE-2026-93451 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-93451){:target="_blank"} and [CVE-2026-108106 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-108106){:target="_blank"}: Updated snappy-java from 1.1.10.8 to 1.1.10.10.
- [CVE-2026-102554 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-102554){:target="_blank"}: Removed the Guava 32.0.1 copy pulled in through protobuf.

#### Medium severity

- [CVE-2026-116590 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-116590){:target="_blank"}: Updated snappy-java to 1.1.10.10.
- [CVE-2026-118259 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-118259){:target="_blank"}: Updated OpenTelemetry Java from 1.62.0 to 1.67.0.

#### Low severity

- [CVE-2026-10532 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-10532){:target="_blank"} and [CVE-2026-9828 :octicons-link-external-16:](https://www.cve.org/CVERecord?id=CVE-2026-9828){:target="_blank"}: Updated Logback from 1.5.25 to 1.6.5.

A Grype scan of the 1.79.1-4 runtime dependencies found no known vulnerabilities.
