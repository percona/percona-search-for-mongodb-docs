## Release Highlights

Percona Search for MongoDB integrates the Apache Lucene-based `mongot` search process with Percona Server for MongoDB. It keeps search indexes synchronized with database changes and processes search requests received through `mongod` or `mongos`.

This release provides the following capabilities:

- [Full-text search](../full-text-search-overview.md): Run relevance-based searches with the `$search` aggregation stage.
- [Vector search](../vector-search-overview.md): Find documents based on semantic similarity with the $vectorSearch aggregation stage. Create vector indexes, filter the search scope, and retrieve a similarity score for each result.

- [Manual embeddings](../embeddings.md#manual-embeddings): Generate document and query embeddings with an external embedding model. Store document embeddings in Percona Server for MongoDB and provide a compatible `queryVector` when running `$vectorSearch`.

- [Automated embeddings with Voyage AI](../embeddings.md#automatic-embeddings): Configure Percona Search for MongoDB to generate embeddings for indexed text and natural-language queries. mongot sends the text to the selected Voyage AI model and keeps the generated embeddings synchronized as documents change. This reduces the amount of embedding code and infrastructure that applications must manage.

- [Replica set and sharded cluster support](../vector-search-deployment.md): Deploy Percona Search for MongoDB with replica sets or sharded clusters. Each replica set or shard has a dedicated mongot instance and search-index storage.

These capabilities support keyword search, semantic search, recommendation systems, and retrieval-augmented generation applications that work directly with data stored in Percona Server for MongoDB.
