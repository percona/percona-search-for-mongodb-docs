# Percona Search for MongoDB {{ page.meta.version }} ({{date.1_70_1}})

[Installation](../install-mongot.md){.md-button}

!!! warning "Technical Preview"
    Percona Search for MongoDB 1.70.1-1 is available as a technical preview.

    We recommend that early adopters use this release for testing purposes only and not in production environments.

We are pleased to introduce **Percona Search for MongoDB 1.70.1-1**. Percona Search for MongoDB integrates the Apache Lucene-based `mongot` search engine with Percona Server for MongoDB. It keeps search indexes synchronized with database changes and processes search requests received through `mongod` or `mongos`.

## Release Highlights

Percona Search for MongoDB 1.70.1-1 provides the following capabilities:

- [Full-text search](../full-text-search-overview.md): Run relevance-based searches with the `$search` aggregation stage.

- [Vector search](../vector-search-overview.md): Find documents based on semantic similarity with the $vectorSearch aggregation stage. Create vector indexes, filter the search scope, and retrieve a similarity score for each result.
