## Initial feature comparison

| Capability                                       | Percona Search for MongoDB                                       | MongoDB Community                  | MongoDB Enterprise Advanced                                 | MongoDB Atlas               |
| ------------------------------------------------ | ---------------------------------------------------------------- | ---------------------------------- | ----------------------------------------------------------- | --------------------------- |
| Operating model                                  | Self-managed or Percona Operator-managed                         | Self-managed                       | `mongot` managed through MongoDB Controllers for Kubernetes | Fully managed               |
| Full-text search                                 | Yes                                                              | Yes                                | Yes                                                         | Yes                         |
| Vector search                                    | Yes                                                              | Yes                                | Yes                                                         | Yes                         |
| `$search`, `$searchMeta`, `$vectorSearch`        | Yes                                                              | Yes                                | Yes                                                         | Yes                         |
| Manual embeddings                                | Yes                                                              | Yes                                | Yes                                                         | Yes                         |
| Automated embeddings with Voyage AI              | Include in planned scope; confirm build support                  | Yes                                | Not currently generally available                           | Yes                         |
| Replica sets                                     | Yes                                                              | Yes                                | Yes                                                         | Yes                         |
| Sharded clusters                                 | Yes                                                              | Yes                                | Yes                                                         | Yes                         |
| Direct client connection to `mongot`             | No                                                               | No                                 | No                                                          | No                          |
| Search infrastructure management                 | User or Percona Operator                                         | User or Kubernetes Operator        | Kubernetes Operator                                         | MongoDB                     |
| Search-node scaling                              | Current Operator preview allows one pod per replica set or shard | User-managed                       | Operator-managed with L7 load balancing                     | Managed by Atlas            |
| Search-index storage                             | User-provisioned dedicated storage                               | User-provisioned dedicated storage | Kubernetes persistent storage                               | Atlas-managed               |
| Search index management through MongoDB commands | Yes                                                              | Yes                                | Yes                                                         | Yes                         |
| UI-based index management                        | Not initially                                                    | No                                 | Limited management visibility                               | Yes                         |
| Native LLM answer generation                     | No, integrate an external LLM                                    | No, integrate an external LLM      | No, integrate an external LLM                               | Requires an LLM integration |
| Product status                                   | Technical preview                                                | Self-managed offering              | Supported deployment path                                   | Managed service             |
